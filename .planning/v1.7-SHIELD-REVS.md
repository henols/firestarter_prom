## 3. Existing Detect-HW Scheme (Anders R41-on-A3)

Per `.planning/v1.7/notes/CHAT-INTEL.md` §1 and the per-rev `.kicad_sch` mine (`.planning/phases/31-upstream-shield-archaeology/mine-notes.md` §Per-rev R41), Anders introduced a version-detect resistor divider at JP4 / R41 feeding Arduino ADC pin A3 starting in the early Rev2 era (commit `a252e39`, 2024-10-08). Rev2.1 carries R41 = 4k7; Rev2.2 uses the same schematic blob as Rev2.1 (R41 = 4k7); Rev2.3 changed R41 to 10k (commit `c2bd111`, 2025-06-24). A discrepancy exists between Anders's CHAT-INTEL statement ("10k version resistor for Rev 2.2", 2025-04-28) and the schematic evidence: the committed schematic for Rev2.2 shows R41 = 4k7. This §3 table captures the per-rev ground truth that Phase 34 firmware ADC-detect plumbing will consume. See `mine-notes.md` §Per-rev-R41 for full grep line references and blob SHAs.

| Rev | R41 value | ADC pin | Voltage divider topology | Schematic citation |
|-----|-----------|---------|--------------------------|--------------------|
| Rev 2.0 (working) | 4k7 (4.7kΩ) | A3 | JP4 (P1_VPP_JMP) → R41 → A3 → GND | `hardware/W27C512Programmer.kicad_sch` blob d2a7f691 on origin/rev2.0 (R41 at line 17520, value at line 17528) |
| Rev 2.1 | 4k7 (4.7kΩ) | A3 | JP4 (P1_VPP_JMP, 1x2 header) → R41 → A3 → GND | `hardware/W27C512Programmer.kicad_sch` blob f3b7a521 on origin/Rev2.1 (R41 at line 18232, value at line 18240) |
| Rev 2.2 | 4k7 (4.7kΩ) per schematic; NOTE: Anders stated "10k" in CHAT-INTEL §1 (2025-04-28) — discrepancy with committed blob | A3 | JP4 (P1_VPP_JMP, 1x2 header) → R41 → A3 → GND | `hardware/W27C512Programmer.kicad_sch` blob f3b7a521 (identical to Rev2.1 blob — same schematic, no standalone Rev2.2 sch committed) |
| Rev 2.3 | 10k (10kΩ) | A3 | JP4 (P1_VPP_JMP, 2x2 header — footprint changed from Rev2.2) → R41 → A3 → GND | `hardware/RelativelyUniversalROMProgrammer.kicad_sch` blob fe35bd78 on origin/Rev2.3 + main (R41 at line 20582, value at line 20591) |

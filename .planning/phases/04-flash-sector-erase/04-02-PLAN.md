<objective>
Add --sector-address option to the CLI erase command and wire it through erase_eprom() → _operation_context so the address is included in the firmware JSON command.

Purpose: The firmware (Plan 04-01) dispatches sector vs chip erase based on handle->address. Python needs to send that address. The _operation_context infrastructure already handles address → JSON (see _setup_operation() around line 176). Only erase_eprom() and create_erase_parser() need changes.

Output: Updated main.py with --sector-address on the erase subcommand, and updated erase_eprom() that accepts and forwards the address.
</objective>

In `erase_eprom()` (around line 581), add an `address_str` keyword parameter and pass it to `_operation_context`:

**Current:**
```python
def erase_eprom(
    self, eprom_name: str, eprom_data_dict: dict, operation_flags: int = 0
) -> bool:
    with self._operation_context(eprom_name, eprom_data_dict, COMMAND_ERASE, operation_flags) as (cmd_data, _, op_name):
```

**Replace with:**
```python
def erase_eprom(
    self, eprom_name: str, eprom_data_dict: dict, operation_flags: int = 0,
    address_str: Optional[str] = None

    with self._operation_context(eprom_name, eprom_data_dict, COMMAND_ERASE, operation_flags, address_str) as (cmd_data, _, op_name):
```

No other changes — `_operation_context` already handles address parsing and inclusion in the command dict.

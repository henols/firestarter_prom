<objective>
Extend `configure_memory` in `firestarter/src/proms/memory.cpp` so every
protocol in `KNOWN_PROTOCOLS` reaches its correct handler via protocol-prefix
dispatch, and delete the orphan `TYPE_FLASH_TYPE_2 = 2` constant per
acceptance criterion 6.

This is the centerpiece of Phase 12 and closes BLOCKER-1 (277 chips currently
falling through to "Memory type 0x%02x not supported") and BLOCKER-2 (52 SRAM
chips currently routed to `configure_eprom`, which enables the 12V VPP boost
regulator on 5V parts — an electrical safety hazard).

Purpose: per CONTEXT.md D1 and D2, the C++ change is the architecturally
primary fix. The Python `_map_data` change (Plan 03) is defense-in-depth. After
this plan lands, `pio test -e native -f test_dispatch` from Plan 01 turns
GREEN.

Output:
- `firestarter/src/proms/memory.cpp` modified:
  - Line 25: `#define TYPE_FLASH_TYPE_2 2` DELETED.
  - Inserted between lines 81 and 83: four new `if (handle->protocol == ...)
    { configure_*(handle); return; }` blocks, in the D2 order: 0x06 →
    `configure_flash3`; {0x05, 0x35, 0x39} → `configure_flash4`; {0x07, 0x08,
    0x0B} → `configure_eprom`; {0x0E, 0x27, 0x28, 0x29} → `configure_sram`.
  - Existing 0x10 and 0x0D blocks (lines 73-81) UNCHANGED.
  - Existing mem_type fallback chain (lines 83-95) UNCHANGED.
</objective>

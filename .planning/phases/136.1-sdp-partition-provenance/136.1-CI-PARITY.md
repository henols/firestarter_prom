### Deviation this task's regeneration caused, fixed in the same task

`tests/test_diff_db_gate.py::TestDiffDbGate::test_diff_db_identity_pass` (GATE-02, an
existing per-chip diff gate comparing `chip_database.json` against a pinned baseline)
went RED immediately after the regeneration commit, reporting all 744 upstream-decoded
chips as "unexplained diffs" — it had no root-cause rule recognizing the three new
`protect_off_before`/`protect_on_after`/`infoic_page_size_raw` keys. Fixed (Rule 1 —
auto-fix, directly caused by this task's own change) by adding a `PROV01_PROTECT_METADATA`
rule to `tools/diff_db.py`, following the file's own established pattern (the same shape
as `PGSZ_PAGE_SIZE`, `RC1_DIP32_27C020`, etc. added by prior phases). `tools/diff_db.py`
is NOT in this plan's `files_modified` frontmatter list — it is a genuine, measured blast-
radius consequence of the chip_database.json regeneration (hard requirement 8's "measure,
don't assume" instruction), not a file this plan set out to touch. See
`136.1-01-SUMMARY.md`'s own Deviations section for the full account and commit hash.

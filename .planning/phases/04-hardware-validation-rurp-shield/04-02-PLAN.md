CLI rhythm (verbatim; per RESEARCH.md §HW-02..§HW-04 + Pitfall #7 "read --verify is loose ROADMAP phrasing"):
```
firestarter write <CHIP> <test.bin>
firestarter verify <CHIP> <test.bin>
firestarter read <CHIP> <readback.bin>
diff <(xxd <test.bin>) <(xxd <readback.bin>)
```
- `firestarter read` does NOT support `--verify`; use the separate `firestarter verify` subcommand (RESEARCH.md Pitfall #7).
- Default `firestarter write` sends `address=0` → chip-erase path on 0x06 chips; pass `-a <nonzero-addr>` to force sector-erase via `flash_type_3.cpp:94-101` (`flash3_erase_execute` branch on `handle->address != 0`).
- `firestarter read -a 0x10000 -s 0x10000` reads 64 KiB starting at offset 0x10000 (matching the SST39SF040 sector-erase write region).

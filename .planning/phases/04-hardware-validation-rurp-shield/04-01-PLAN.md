| Old (flat top-level)        | New (nested under manufacturer)                                          |

| `select(.name == $t)`        | `select(.part_number == $t)`                                              |

| `.["has-chip-id"]`            | `.programming.chip_id_check`                                              |

Note on `MEMORY_SIZE_HEX` (firestarter_test.sh:50 / write_test.sh:36 variable name):
- The old query returned an integer expressed in hex (e.g. `0x10000` for 64 KiB) — the variable name reflects historical schema.
- The new `electrical.size_bytes` returns a plain integer (e.g. `65536`). The script's downstream `dd` invocations use `$MEMORY_SIZE_HEX` as a byte count; an integer is fine (bash arithmetic auto-coerces). No need to convert to hex; just keep the variable name OR rename to `MEMORY_SIZE`. Executor's call.

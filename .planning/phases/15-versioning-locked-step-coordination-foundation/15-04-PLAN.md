    ## Failure recovery

    Lockstep is enforced at WRITE TIME via the explicit `BETA_VERSION` input. If one workflow fails after the other succeeded, the operator's next action depends on the failure:

    | Failure | Recovery |
    |---------|----------|
    | App workflow CI test step failed (no PyPI upload happened) | Fix the failing test; re-trigger the app workflow with the SAME `BETA_VERSION`. No drift — PyPI/GitHub Release for app does not yet exist. |
    | App workflow succeeded; firmware workflow failed at build/codegen gate | Fix the firmware issue; re-trigger the firmware workflow with the SAME `BETA_VERSION`. App side is already published with the chosen version; firmware catches up. |
    | App workflow created PyPI release; same workflow re-triggered for an unrelated reason | PyPI rejects re-upload of the same version (HTTP 400, "File already exists"). Operator must increment `BETA_VERSION` to the next `bN` and run BOTH workflows again with the new string — keeping lockstep. **Known gap** per D-03; idempotent re-publish is deferred to a future milestone. |
    | Firmware GitHub Release exists, app PyPI publish failed | Manually delete the firmware GitHub Release tag (rare), or increment `BETA_VERSION` and re-cut both. |

    ## Known gaps (carry-forward to a future milestone)

    - **Signed release artifacts**: out of scope for v1.4. Would cover both stable and beta in a dedicated milestone.

    #!/usr/bin/env bash
    # lockstep-dryrun-fixture.sh
    #
    # Proves the VER-03 lockstep contract: invoking both sub-repos' update_version.py
    # --beta --dry-run --set-version <X.Y.ZbN> produces byte-identical DRY_RUN output.
    #

    #   BETA_VERSION=3.1.0b2 bash lockstep-dryrun-fixture.sh   # override
    #
    # Exit code: 0 on lockstep match; 1 on any mismatch or script error.

    set -euo pipefail

    SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
    META_REPO_ROOT="$(cd "$SCRIPT_DIR/../../.." && pwd)"
    APP_REPO="$META_REPO_ROOT/firestarter_app"
    FW_REPO="$META_REPO_ROOT/firestarter"
    BETA_VERSION="${BETA_VERSION:-1.2.3b1}"

    echo "LOCKSTEP DRY-RUN FIXTURE"
    echo "========================"
    echo "Meta-repo root: $META_REPO_ROOT"
    echo "App repo:       $APP_REPO"
    echo "Firmware repo:  $FW_REPO"
    echo "BETA_VERSION:   $BETA_VERSION"
    echo ""

    # Verify both sub-repos exist with the expected script
    for REPO_PATH in "$APP_REPO" "$FW_REPO"; do
        if [[ ! -f "$REPO_PATH/.github/scripts/update_version.py" ]]; then
            echo "ERROR: $REPO_PATH/.github/scripts/update_version.py not found"
            exit 1
        fi
    done

    # Invoke app dry-run
    APP_OUTPUT="$(cd "$APP_REPO" && python3 .github/scripts/update_version.py --beta --dry-run --set-version "$BETA_VERSION" 2>&1)"

    echo "Firmware emits:  DRY_RUN: $FW_VERSION"
    echo ""

    # Compare
    if [[ "$APP_VERSION" == "$FW_VERSION" ]] && [[ "$APP_VERSION" == "$BETA_VERSION" ]]; then
        echo "LOCKSTEP OK"
        exit 0
    else
        echo "LOCKSTEP FAILED: app=$APP_VERSION firmware=$FW_VERSION expected=$BETA_VERSION"
        echo ""
        echo "--- App stdout ---"
        echo "$APP_OUTPUT"
        echo "--- Firmware stdout ---"
        echo "$FW_OUTPUT"

Add a new method `get_adapter_table()` to `EpromDatabase`, after `get_bus_config()` (around line 285).

The method builds a complete physical-pin-to-signal table from the raw `pinouts.json` data,
without going through `pin_conversions`. The pinout file already says which physical DIP pins
carry which signals.

```python
def get_adapter_table(self, pin_count: int, pinout_key: str) -> list:
    """
    Returns [(pin_number, signal_name), ...] for every pin 1..pin_count.
    Derived from pinouts.json. Returns [] if the pinout key is unknown.
    """
    pin_map_data = self.get_pin_map(pin_count, pinout_key)
    if not pin_map_data:
        return []

    pin_signals = {}  # physical pin number -> signal string

    def _assign(pins, signal):
        for p in (pins if isinstance(pins, list) else [pins]):
            if p in pin_signals and signal not in pin_signals[p]:
                pin_signals[p] = pin_signals[p] + "/" + signal
            else:
                pin_signals[p] = signal

    _assign(pin_map_data.get("vcc-pin", []), "VCC")
    _assign(pin_map_data.get("gnd-pin", []), "GND")
    _assign(pin_map_data.get("ce-pin", []), "CE")
    _assign(pin_map_data.get("oe-pin", []), "OE")
    _assign(pin_map_data.get("pgm-pin", []), "PGM")
    _assign(pin_map_data.get("vpp-pin", []), "VPP")

    for i, p in enumerate(pin_map_data.get("address-bus-pins", [])):
        if p not in pin_signals:
            pin_signals[p] = f"A{i}"

    for i, p in enumerate(pin_map_data.get("data-bus-pins", [])):
        if p not in pin_signals:
            pin_signals[p] = f"D{i}"

    return [(p, pin_signals.get(p, "NC")) for p in range(1, pin_count + 1)]
```

Note: pins that appear in multiple categories (e.g. pin 22 on DIP28_27512 is both `oe-pin`
and `vpp-pin`) will have their signals joined as "OE/VPP". The order of `_assign` calls
controls precedence — VPP is last so it appends rather than overwrites.

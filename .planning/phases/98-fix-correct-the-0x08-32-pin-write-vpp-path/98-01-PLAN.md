<objective>
Deliver the RC-1 primary fix surface (classified host-pinout, per
97-RCA-FINDINGS): a new scoped `DIP32_27C020` pinout that moves DIP pin 31 OUT of
the address bus (where `DIP32_STD` models it as A18 / bus line 22) and
re-expresses it as a held program-active PGM control, while keeping VPP on pin 1.
Assign it via `build_db.py` ONLY to the `0x08` ≤256K class (AM27C020) so the 512K
AM27C040 (524288) and 1M AM27C080 (1048576) — which legitimately use pin 31 = A18
— stay structurally excluded on `DIP32_STD`. That structural exclusion is the
host half of the D-04 alias-collision guard. Regenerate the DB, re-baseline, and
prove the change is scoped via `diff_db.py` + `check_dispatch.py` on py3.11.

Purpose: lands the host-pinout surface, the FIX-03 lockstep/scoping discipline,
and the SAFE-02 py3.11 CI gate. It also defines the bus-config shape (pin 31 as a
non-address / static-high line, NOT an address line) that Plan 02's firmware
PGM-assert reads — so this plan is the upstream contract for Wave 2.

Output: `DIP32_27C020` in pinouts.json; a size-keyed `resolve_pinout_key` arm;
regenerated chip_database.json (AM27C020 → DIP32_27C020); updated diff baseline;
green host gate on py3.11.
</objective>

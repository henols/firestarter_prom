**Phase 18 CLI flags (final, verbatim — DOC-01 + DOC-02 must use these exact strings):**
- `firestarter fw -i` — install firmware (existing flag, stable channel default)
- `firestarter fw -i --pre` — install latest pre-release firmware (mirrors `pip install --pre`)
- `firestarter fw -i --firmware-version X.Y.ZbN` — pin exact firmware tag (also accepts
  `X.Y.Z` stable form and `X.Y.ZrcN` release-candidate form)
- `firestarter fw -i --stable` — explicit stable channel (overrides magic-default auto-routing)
- `firestarter fw --list` — enumerate available firmware releases for the configured board
- `firestarter fw --list --pre` — filter list to pre-releases only
- `firestarter fw --list --stable` — filter list to stable releases only
- `firestarter fw --list --json` — JSON output (only valid with `--list`)

**Magic-default INFO line (verbatim from Phase 18 caplog — DOC-01 must quote this):**

> Beta app detected — defaulting to --pre. Use --firmware-version X.Y.Z to pin a stable version.

**Argparse mutex constraints (DOC-01 should note):**
- `--pre`, `--firmware-version`, and `--stable` are mutually exclusive (3-way mutex).
- `-i/--install` and `--list` are mutually exclusive.
- `--json` requires `--list`.
- Invalid `--firmware-version` (regex `^[0-9]+\.[0-9]+\.[0-9]+((b|rc)[0-9]+)?$`) fails fast
  with no network call.

**Phase 15 PEP 440 regex (DOC-03 must quote in Version string format section):**

```
^[0-9]+\.[0-9]+\.[0-9]+(b|rc)[0-9]+$
```

Accepted: `3.1.0b1`, `3.1.0b2`, `3.1.0rc1`, `0.0.1b1`, `1.2.3rc2`.
Rejected: `3.1.0beta1`, `3.1.0-b1`, `3.1.0B1`, `3.1.0a1`, `3.1.0`, `3.1.0.post1`.

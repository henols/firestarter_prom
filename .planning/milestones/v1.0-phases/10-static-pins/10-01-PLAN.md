# Phase 10-01 — Static Pins, Multi-CE, Address Bus Correctness

## Goal

Replace the hardcoded `ADDRESS_LINE_13` for 24-pin chips with a data-driven
`static_high_mask` mechanism, and fix the dead condition in
`mem_util_calculate_top_address_register`.

## Changes (in execution order)

### Wave 1 — Python side

**W1-A: `pinouts.json`**
Add `static-high-pins` to DIP24 entries. DIP24 chip pin 24 (VCC) sits at DIP32
socket position 28, which is wired to bus line 13. Driving bus line 13 HIGH supplies
the chip's VCC through the socket. This is the hardware reason for the ADDRESS_LINE_13
hack.

- `DIP24_2716`: add `"static-high-pins": [24]`
- `DIP24_2732`: add `"static-high-pins": [24]`

**W1-B: `pin_conversions[24]` in `database.py`**
Add `24: 13` to DIP24 pin_conversions so the VCC pin (at socket position 28 = bus line 13)
is translateable. This enables `get_bus_config()` to resolve `static-high-pins` for DIP24.

**W1-C: `get_bus_config()` in `database.py`**
After the existing rw-pin and vpp-pin handling, read `static-high-pins` from the pinout,
translate each through pin_conversions, and emit them as a `"static-high"` array in the
bus-config output dict.

### Wave 2 — Firmware side

**W2-A: `bus_config_t` in `firestarter.h`**
Add one field after `vpp_line`:
```c
uint32_t static_high_mask;  // bus lines unconditionally driven HIGH
```

**W2-B: `parse_bus_config()` in `json_parser.c`**
- Initialize `handle->bus_config.static_high_mask = 0` at start of function.
- Add a new branch for key `"static-high"`: parse the integer array and OR each element
  as `1UL << value` into `static_high_mask`. Each element is a single token (integer),
  so the pair_tokens count = 1 (key) + 1 (array token) + N (elements).

**W2-C: `mem_util_remap_address_bus()` in `memory.cpp`**
After the vpp_line block, add:
```c
reorg_address |= config.static_high_mask;
```

**W2-D: `mem_util_calculate_msb_register()` in `memory.cpp`**
Remove the special case:
```c
if (handle->pins == 24) {
    msb |= ADDRESS_LINE_13;
}
```
The static_high_mask mechanism in mem_util_remap_address_bus now handles this via data.

**W2-E: `mem_util_calculate_top_address_register()` in `memory.cpp`**
Replace the dead compound condition:
```c
// Before:
if (((top_address & READ_WRITE) && READ_WRITE == WRITE_FLAG) || handle->pins < 32) {
// After:
if (handle->pins < 32) {  // VPE_TO_VPP shares the A16 bit; exclude for 32-pin chips
```

### Wave 3 — Build

- `pio run -e uno` — must build clean
- `pio run -e leonardo` — must build clean

## Success Criteria

- DIP24_2716 and DIP24_2732 bus-config JSON includes `"static-high": [13]`
- `mem_util_remap_address_bus` applies static_high_mask unconditionally
- `mem_util_calculate_msb_register` has no 24-pin special case
- `mem_util_calculate_top_address_register` has no dead comparison
- Both firmware targets build clean
- Existing verified chips (W27C512, 29F040, AT28C256) bus configs unchanged (no static-high)

<objective>
Add sector erase to flash_type_3.cpp: when CMD_ERASE is issued with handle->address != 0, perform AMD sector erase at that address instead of chip erase.

Purpose: Currently flash3_erase_execute() always does chip erase. Sector erase uses the same 6-cycle AMD sequence but writes 0x30 to the sector address (not 0x10 to 0x5555). The address is already parsed from JSON into handle->address by the existing json_parser.

Output: flash_type_3.cpp with a static flash3_sector_erase() helper and updated flash3_erase_execute() branching on handle->address.
</objective>

**Step 2** — Add the sector erase implementation. Insert after `flash3_erase_execute()`:
```c
void flash3_sector_erase(firestarter_handle_t* handle, uint32_t sector_address) {
    byte_flip_t sector_erase_seq[6] = {
        {0x5555, 0xAA},
        {0x2AAA, 0x55},
        {0x5555, 0x80},
        {0x5555, 0xAA},
        {0x2AAA, 0x55},
        {sector_address, 0x30},
    };
    flash_util_byte_flipping(handle, sector_erase_seq, 6);
}
```

Note: `byte_flip_t` is defined in `flash_utils.h` and already included. `flash_util_byte_flipping()` accepts `const byte_flip_t*` — passing a non-const stack array to a const pointer is valid C++.

**Step 3** — Update `flash3_erase_execute()` to branch on address:

**Current:**
```c
void flash3_erase_execute(firestarter_handle_t* handle) {
    debug("Erase");
    flash_execute_command(FLASH_ERASE);
}
```

**Replace with:**
```c
void flash3_erase_execute(firestarter_handle_t* handle) {
    if (handle->address != 0) {
        debug("Sector erase");
        flash3_sector_erase(handle, handle->address);
    } else {
        debug("Chip erase");
        flash_execute_command(FLASH_ERASE);
    }
}
```

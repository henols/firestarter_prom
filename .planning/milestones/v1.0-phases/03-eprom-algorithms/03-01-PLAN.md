<objective>
Fix eprom.cpp so UV-EPROM programming uses the correct pulse timing and VPP routing for each of the three protocols (0x07, 0x08, 0x0B), and ensure VPP is validated before every write (REQ-SAF-01).

Purpose: Currently eprom.cpp treats all EPROMs identically — same VPP routing (FLAG_VPE_AS_VPP flag), same pulse width (pulse_delay from Python, currently 0), and VPP check only when chip_id > 0. With protocol in handle->protocol (populated by Phase 02), we can dispatch correctly:
- EPROM_STD (0x07) and EPROM_QUICK (0x08): VPE_TO_VPP path, 1ms / 100µs defaults
- EPROM_LEGACY (0x0B): direct REGULATOR-only path, 500µs default

Output: eprom.cpp with four targeted fixes. No new files, no architectural changes.
</objective>

<task type="auto">
  <name>Task 2: Route VPP based on protocol in eprom_write_execute()</name>
  <files>firestarter/src/proms/eprom.cpp</files>
  <action>
In `eprom_write_execute()`, find the VPP routing block (around line 134):

**Current:**
```c
if (handle->firestarter_get_control_register(handle, REGULATOR) == 0) {
    if (is_flag_set(FLAG_VPE_AS_VPP)) {
        handle->firestarter_set_control_register(handle, REGULATOR, 1);
    } else {
        handle->firestarter_set_control_register(handle, REGULATOR | VPE_TO_VPP, 1);
    }
    delay(500);
}
```

**Replace with:**
```c
if (handle->firestarter_get_control_register(handle, REGULATOR) == 0) {
    if (handle->protocol == 0x0B || is_flag_set(FLAG_VPE_AS_VPP)) {
        // EPROM_LEGACY: direct VPE path — no VPE_TO_VPP dropping resistor
        handle->firestarter_set_control_register(handle, REGULATOR, 1);
    } else {
        // EPROM_STD / EPROM_QUICK: VPE_TO_VPP dropping path for precise VPP
        handle->firestarter_set_control_register(handle, REGULATOR | VPE_TO_VPP, 1);
    }
    delay(500);
}
```

The `|| is_flag_set(FLAG_VPE_AS_VPP)` preserves backward compatibility when `handle->protocol == 0` (old Python without algorithm field).

<objective>
Fix database.py so it reads `algorithm` directly from the integer stored by parse_db_2.py and passes it through to the firmware command dict.

Purpose: Currently `_map_data()` reverse-maps the algorithm string back to an integer using PROTOCOL_MAP (lines 324-329), and `convert_to_programmer()` never includes algorithm in the output at all. After Plan 01-01 fixes parse_db_2.py to store `programming.algorithm` as an integer, this plan wires it through database.py so the firmware actually receives it.

Output: database.py where `_map_data()` does a direct integer read, `convert_to_programmer()` emits `"algorithm"`, and VPP comes from `vpp_mv` millivolts when available.
</objective>

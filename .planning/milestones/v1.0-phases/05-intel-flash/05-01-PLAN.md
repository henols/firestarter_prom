<objective>
Implement the Intel 28F Flash handler: new flash_intel.h + flash_intel.cpp with configure_flash_intel(), and a one-line protocol dispatch in memory.cpp that intercepts protocol 0x10 BEFORE the mem_type checks.

Purpose: Intel 28F chips (28F256, 28F512, 28F010, 28F020, etc. — 39 chips in the database, protocol 0x10) use a command-register architecture entirely different from AMD-style flash. The database stores them with mem_type=1 (EPROM), so without a protocol-first dispatch they fall through to configure_eprom(), which writes garbage. With this plan, protocol 0x10 gets its own handler that uses the Intel command set and 12V VPP on pin 1.

Intel 28F command set:
- 0x40 + data → program one byte at target address; poll SR.7=1 to confirm
- 0x20 + 0xD0 → chip erase; poll SR.7=1 (up to ~10s) to confirm
- 0xFF → reset to read array mode
- SR.7=1 ready, SR.4=VPP error, SR.3=program/erase error

VPP: REGULATOR | P1_VPP_ENABLE routes 12V to pin 1 of the socket. VPP must be stable before issuing write/erase commands. 500ms settling delay after enabling.

Output: Two new files plus a 4-line diff in memory.cpp.
</objective>

```cpp
/*
 * Project Name: Firestarter
 * Copyright (c) 2024 Henrik Olsson
 *
 * Permission is hereby granted under MIT license.
 */

#include "flash_intel.h"

#include <Arduino.h>

#include "firestarter.h"
#include "logging.h"
#include "memory_utils.h"
#include "operation_utils.h"
#include "rurp_shield.h"

void flash_intel_write_init(firestarter_handle_t* handle);
void flash_intel_write_execute(firestarter_handle_t* handle);
void flash_intel_erase_execute(firestarter_handle_t* handle);
void flash_intel_cleanup(firestarter_handle_t* handle);
static bool flash_intel_poll_sr(firestarter_handle_t* handle, uint16_t timeout_ms);

void configure_flash_intel(firestarter_handle_t* handle) {
    debug("Configuring Intel Flash");
    handle->firestarter_operation_end = flash_intel_cleanup;
    switch (handle->cmd) {
        case CMD_WRITE:
            handle->firestarter_operation_init = flash_intel_write_init;
            handle->firestarter_operation_main = flash_intel_write_execute;
            break;
        case CMD_ERASE:
            handle->firestarter_operation_main = flash_intel_erase_execute;
            break;
        case CMD_BLANK_CHECK:
            handle->firestarter_operation_main = mem_util_blank_check;
            break;
    }
}

void flash_intel_write_init(firestarter_handle_t* handle) {
    handle->firestarter_set_control_register(handle, REGULATOR | P1_VPP_ENABLE, 1);
    delay(500);
    if (is_flag_set(FLAG_CAN_ERASE) && !is_flag_set(FLAG_SKIP_ERASE)) {
        flash_intel_erase_execute(handle);
    }
    if (!is_flag_set(FLAG_SKIP_BLANK_CHECK)) {
        mem_util_blank_check(handle);
    }
}

void flash_intel_write_execute(firestarter_handle_t* handle) {
    for (uint32_t i = 0; i < handle->data_size; i++) {
        uint32_t address = handle->address + i;
        uint8_t data = handle->data_buffer[i];
        handle->firestarter_set_data(handle, address, 0x40);  // program setup
        handle->firestarter_set_data(handle, address, data);  // program data
        if (!flash_intel_poll_sr(handle, 150)) {
            return;
        }
    }
}

void flash_intel_erase_execute(firestarter_handle_t* handle) {
    handle->firestarter_set_control_register(handle, REGULATOR | P1_VPP_ENABLE, 1);
    delay(500);
    handle->firestarter_set_data(handle, 0, 0x20);  // erase setup
    handle->firestarter_set_data(handle, 0, 0xD0);  // erase confirm
    if (!flash_intel_poll_sr(handle, 15000)) {
        return;
    }
    debug("Erase complete");
}

void flash_intel_cleanup(firestarter_handle_t* handle) {
    handle->firestarter_set_data(handle, 0, 0xFF);  // reset to read array mode
    handle->firestarter_set_control_register(handle, REGULATOR | P1_VPP_ENABLE, 0);
}

static bool flash_intel_poll_sr(firestarter_handle_t* handle, uint16_t timeout_ms) {
    unsigned long deadline = millis() + timeout_ms;
    while (millis() < deadline) {
        uint8_t sr = handle->firestarter_get_data(handle, 0);
        if (sr & 0x80) {
            if (sr & 0x10) {
                firestarter_error_response("Intel flash: VPP error");
                handle->firestarter_set_data(handle, 0, 0xFF);
                return false;
            }
            if (sr & 0x08) {
                firestarter_error_response("Intel flash: program error");
                handle->firestarter_set_data(handle, 0, 0xFF);
                return false;
            }
            return true;
        }
    }
    firestarter_error_response("Intel flash: SR timeout");
    handle->firestarter_set_data(handle, 0, 0xFF);
    return false;
}
```

**Design notes for the executor:**
- `configure_memory()` (memory.cpp lines 61-67) pre-sets firestarter_get_data, firestarter_set_data, firestarter_set_control_register, etc. BEFORE calling configure_flash_intel(). These pointers are valid and ready to use.
- `flash_intel_write_init()` enables VPP once; it stays on through all flash_intel_write_execute() calls since it's just a hardware register. flash_intel_cleanup() disables it.
- `flash_intel_erase_execute()` enables VPP itself to handle the standalone CMD_ERASE path (where write_init is not called). Double-enabling is idempotent.
- The 15s timeout in flash_intel_poll_sr for erase covers worst-case chip erase time for Intel 28F020 (spec: ~10s typical, ~14s max).
- SR.7=1 means WSM ready. SR.4=VPP low error. SR.3=program/erase controller error.

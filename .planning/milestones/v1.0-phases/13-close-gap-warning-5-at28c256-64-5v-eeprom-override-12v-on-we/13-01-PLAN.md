<objective>
Add a new regression guard to `firestarter_app/tools/check_dispatch.py` that asserts no chip with `pinout == "DIP28_2764"` AND `electrical.type == "Flash/EEPROM"` routes to `configure_eprom`. This is WARNING-5: applying 12V `P1_VPP_ENABLE` to socket pin 1 of a DIP28_2764 5V EEPROM hits its A14 address line — hardware damage.

Purpose: Establish the failing-test gate before the fix lands (per Validation contract Wave 0). On the current DB the guard MUST report 23 violations and exit 1, proving it catches the hazard. After Plan 02 regenerates the DB with `algorithm=0x0D` on those chips, the same guard will PASS.

Output: Modified `firestarter_app/tools/check_dispatch.py` with a new module-top constant `_28C_EEPROM_HAZARD_PINOUT`, a per-chip check inside the existing scan loop, a violation-collector list, a threshold-truncated FAIL block, and an updated PASS summary line.
</objective>

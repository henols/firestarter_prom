**Milestone goal (verbatim from ROADMAP.md):** Make the `firestarter_app` Python host code structured, readable, and spaghetti-free — without changing the wire protocol or end-user command surface (except intentional, documented bug fixes). Specifically: decompose the 418-line `main()` dispatcher and the 1037-line `serial_comm.py`; migrate argparse to Click; introduce a characterization test safety net on the currently-untested core paths; consolidate wire-protocol constants; unify error handling; and gate everything with ruff + ruff-format + mypy + CI.

**Actual ship outcome:** All 27 in-scope refactoring requirements DELIVERED across Phases 36-42; DOC-01/DOC-02/MS-01 VERIFIED at Phase 43 close. `main.py` trimmed 932 → 35 lines; `cli_handlers.py` houses 14 `@cli.command()` + `dev` group with 4 sub-commands; `serial_comm.py` split into `frame_parser.py` + `codec.py` (transport split); `chip_resolver.py` provides single chip-lookup call site (eliminates 9× copy-paste). 2 latent bugs fixed as INTENTIONAL BEHAVIOR CHANGE: BUG-1 `build_arg_flags` truthiness (Phase 41 Plan 41-01, commit `6241dba`); BUG-2 `eprom_operations._run_state_machine` except-clause split (Phase 42 Plan 42-01, commit `04a0c13`). 22 of 29 syrupy snapshots updated in Phase 41 to capture Click's `--help/--version/error` format (mechanical impossibility to keep snapshots argparse-byte-identical without a custom Click formatter — out-of-scope architectural work; CLI behavioral contract preserved). Coverage 70.12% at close (≥ 70% floor; raised from 50% by Phase 42 Plan 42-03). Ship tag `3.0.0b7` beta-only per D-09 (stable `3.0.1` deferred to v1.9 read-bug fix per D-17v2 carry-forward).

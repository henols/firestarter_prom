<objective>
Consolidate all application exception classes into a single new flat leaf module
`firestarter/exceptions.py`, then repoint every import / raise / except site to pull
from it. This is the first extraction in Phase 38 because `exceptions.py` is a pure leaf
(stdlib only) and its existence unblocks Phase 39's `chip_resolver.py` (which imports
`ChipNotFoundError`).

Implements STRUCT-04. Honors locked decisions D-01 (8-class membership including
`FirmwareOperationError` + new `ChipNotFoundError` stub), D-02 (Avrdude*Error stay in
avr_tool.py — the one documented SC#1 deviation), D-03 (preserve inheritance exactly —
no unifying `FirestarterError` base), D-04 (all sites repointed; exceptions.py is a pure
leaf).

Purpose: behavior-preserving move + repoint. Zero runtime behavior change. The full
Phase 36 safety net is the acceptance signal.
Output: `firestarter/exceptions.py` (new) + repointed imports in serial_comm.py,
eprom_operations.py, firmware.py, hardware.py.
</objective>

<objective>
Extract the inline hex/decimal address+size parsing from `eprom_operations._setup_operation`
into a new flat stdlib-only leaf `firestarter/address_parser.py` with an explicit `ValueError`
contract, then update the single call site to wrap the (now-raising) parser calls in
`try/except ValueError` so the CLI-observable behavior stays byte-identical.

Implements STRUCT-03. Honors D-11 (`parse_address`/`parse_size` raise `ValueError` on bad
input; return `None` for `None`), D-12 (`_setup_operation` wraps calls preserving the exact
log lines + the `(None, 0)` graceful-fail return), D-13 (the critical subtlety:
`command_dict["address"]` is set ONLY inside `if address:`; `addr = 0` default stays owned by
`_setup_operation` for the `memory-size = addr + read_size` computation; the `memory-size` write
stays gated on `cmd == COMMAND_READ and size`).

Note: this plan touches `eprom_operations.py`, which is also touched by Plan 01 (exception
repoint) and Plan 05 (dead-code sweep). It serializes AFTER Plan 01 (needs that import surface
stable) and BEFORE Plan 05. It does NOT depend on Plan 02/03 (address_parser is independent of
frame_parser/codec) but runs in its own wave for sequential execution.

Purpose: behavior-preserving extraction with a raise-then-catch contract that keeps the same
external behavior. Output: address_parser.py (new), test_address_parser.py (new),
eprom_operations.py call site rewritten.

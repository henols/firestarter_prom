# Milestone v1.18 Audit — AM27C020 0x08 Write-Path RCA & Fix

**Audited:** 2026-07-01
**Status:** `tech_debt` — all 11 requirements satisfied, no critical blockers; accumulated deferrals (headline: AM27C020 graduation → FUT-08) and Nyquist partials to review.

## Milestone Goal

Root-cause why the AM27C020 (`0x08` EPROM-QUICK, 32-pin, 256K×8 CMOS EPROM) programs **0 bits**, fix the firmware/host `0x08` 32-pin write/VPP path, and bench-prove byte-exact write→verify on real silicon — **or cleanly defer graduation** (the W29C040 lesson) if the chip isn't reliably programmable. Gated on a Tier-0 silicon-writability pre-flight (PRE-01).

## Outcome

RCA succeeded (RC-1: DIP32 pin 31 modeled as address line A18 instead of held program-active). The fix (`DIP32_27C020` pinout routing pin 31 off the address bus onto `CTRL_READ_WRITE` 0x40, a revision-invariant bit distinct from the `0x08` VPP alias) proved **bench-effective** — it refuted the Phase-97 0-bits signature (write#1 = 60/64 byte-exact). But the program window is **marginal/unreliable** (write#2 = 0/64), so no byte-exact graduation was reached. BENCH-01's two-branch criterion is satisfied via the **clean documented deferral** branch: AM27C020 stays `open-defect-carried` in the PROTOCOL-LEDGER, and FUT-06 is retired-by-replacement → **FUT-08** (characterize program-window VPP-under-load + timing).

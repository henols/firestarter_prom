## Key R-designator + signal aliases (constant across revs unless flagged in §4 notes)

From `firestarter/include/rurp_shield.h` (extracted for executor reference):
- VPP regulator boost enable: control-register bit `REGULATOR (0x80)`
- VPE→VPP path: control-register bit `VPE_TO_VPP (0x01)` (shared with ADDRESS_LINE_16 for 32-pin chips — see memory.cpp:142-145)
- Socket pin 1 VPP route: control-register bit `P1_VPP_ENABLE (0x08)`
- A9 VPP route (chip-ID read): control-register bit `A9_VPP_ENABLE (0x02)`
- VPE direct PGM: control-register bit `VPE_ENABLE (0x04)`
- Voltage divider resistor pair: `VALUE_R1=270000` Ω, `VALUE_R2=44000` Ω (defaults — overridable in EEPROM rurp_configuration_t.r1/r2)
- Calibration substrate (legacy fall-through for pre-detect-resistor boards): `rurp_configuration_t.hardware_revision` byte in EEPROM (per Phase 31 D-07; preserved by Phase 34 GATE)

These five control-register bits + R1/R2 divider + hardware_revision EEPROM byte are the firmware-side surface. Any §4 row that claims "control-line routing changed" must cite which of these bits is affected.

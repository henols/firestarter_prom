Wire format unchanged (Phase 34 D-09 lock honored): all firmware-side `LOG_INFO_ID_U8(MSG_INFO_*, ...)` + `LOG_OK_ID_*(MSG_OK_CFG, ...)` call sites stay byte-identical; only the host-side rendering changes.

Plan 01 (firmware) and this plan are co-designed: Plan 01's CR-02 hard-fail-loud emit re-uses MSG_INFO_HW with payload `REVISION_UNKNOWN` (0xFE); this plan's MSG_INFO_HW silkscreen branch ensures the boot-time warn surfaces as `"WARN: HW: rev_unknown"` instead of `"WARN: HW: Rev254"`. Together the operator gets a clear loud warning on detect-inconclusive boots.

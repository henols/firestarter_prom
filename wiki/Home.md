# Firestarter Wiki

Firestarter is an Arduino-based programmer for EPROM, Flash, and SRAM devices built around the RURP shield, made up of two companion repositories: the AVR firmware and the Python host CLI. This wiki collects the reference documentation for both.

See [How this wiki is published](How-This-Wiki-Is-Published) for how these pages are kept in sync with the source repository, and why you should not edit them here directly.

## Which branch this wiki tracks

This wiki is published from the project's `beta` integration branch, not from a tagged release. A page here can describe behavior that has landed on `beta` but has not yet reached a stable release. If something you read does not match the version you installed, check which branch or release you are running.
